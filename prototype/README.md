# Zucco — кириллча дизайн пакети

Яшил ва оқ ранглардаги CRM/ERP макетлари. 22 та саҳифа, 16 та қўшимча ҳолат, 38 та таҳрирланадиган SVG ва 38 та PNG. Барча интерфейс матнлари ўзбек кириллицасида; брендлар ва техник кодлар ўз ёзувида қолдирилган.

**Кўриш:** `screens.html` — барча макетлар галереяси; `index.html` — ишлайдиган маҳаллий прототип. Браузерда тўғридан-тўғри очилади. Сервер ёки dependency ўрнатиш талаб этилмайди. Шрифтлар пакетга киритилган.

Қўшимча ҳолатлар: тўлов, лидни талабага айлантириш, йўқотиш сабаби, қўшимча гуруҳга ёзиш, музлатиш, ўқув тўловини ҳисоблаш, маош схемаси, маош ҳисоблаш, харажат, янги ходим, SMS ёзиш, ўқитувчи кўриниши, гуруҳ яратиш, бўш қидирув, кириш чеклови, танга етишмаслиги.

Барча файл ва маршрутлар `screen-manifest.json` да берилган. Галерея орқали қўшимча ҳолатни ҳам тўғридан-тўғри очиш мумкин.

## Бизнес қоидалари

Лиддан талаба яратиш/мавжудини боғлаш, кўп гуруҳга ёзиш, пул ҳисоби ва даври бор тўлов, 4 хил ўқув тўловини ҳисоблаш, 4 хил маош схемаси, тасдиқлаш ва бир марта тўлаш, музлатиш, ҳақиқий permission калитлари ва SMS ҳолатлари мослаштирилган.

Давоматда «Қатнашди» га ўтиш автоматик 5 танга беради; ундан чиқиш 5 тангани қайтаради. Қўшимча +1/+5 рағбат алоҳида амал. Музлатилган талаба ва келажак дарси давомати чекланган.

Тўлиқ шартнома харитаси ва интеграция чегаралари: [BUSINESS-ALIGNMENT.md](BUSINESS-ALIGNMENT.md).

## Figma'га импорт

1. Янги ёки мавжуд Design файлини очинг.
2. `exports` ичидаги керакли `.svg` файлларни canvas'га судраб киритинг.
3. Пакетдаги Inter шрифтларини ўрнатинг ёки Inter мавжудлигини текширинг.
4. Ҳар бир SVG'ни алоҳида 1440 px кенгликдаги frame сифатида жойлаштиринг.

Матнлар, иконкалар ва шакллар вектор. PNG'лар кўриш учун. SVG импорт Auto Layout, reusable component, variant ёки variable binding яратмайди; булар Figma'да алоҳида тузилади.

**Асл Figma файли бу янгилашда ўзгармаган:** коннектор Starter лимити туфайли ёзишни рад этган. Маҳаллий пакет ва SVG'лар янгиланган натижадир.

## Текширув ва қайта йиғиш

`business-verification.json`: 27 та текширув, 110 та responsive ҳолат, console хатоси йўқ. `exports/export-audit.json`: 38 та таҳрирланадиган вектор макет. Бу маҳаллий прототип текширувлари; live backend интеграциясининг натижаси эмас.

Қайта текшириш учун Node.js, Playwright ва Chrome; галерея тасвири учун Sharp талаб этилади. Permission манбасини солиштириш тести Zucco репозиторийси ичида ишлатилади.

```powershell
node tools/verify-business.cjs
node tools/export-design.cjs
node tools/build-gallery.cjs
```

Керак бўлса `ZUCCO_PLAYWRIGHT`, `ZUCCO_CHROME` ва `ZUCCO_SHARP` муҳит ўзгарувчилари орқали ўрнатилган модул/браузер йўлини беринг. Аввалги `verify-prototype.cjs` ва `verify-platform.cjs` кириш нуқталари янги текширувга йўналтирилган.

Намунавий маълумотлар хотирада сақланади; refresh уларни дастлабки ҳолатга қайтаради. Реал тўлов, SMS, аутентификация ёки принтерга ҳеч нарса юборилмайди. Backend ва `apps/crm-web` коди ушбу дизайн иши учун ўзгартирилмаган.
